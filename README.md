# open-wms

#### 介绍
易软通开源 OpenWMS 是一款基于现代技术栈开发的轻量级仓库管理系统（Warehouse Management System），遵循 Apache 2.0 开源协议，面向中小型企业提供免费的仓库管理解决方案。核心功能涵盖库存管理、入库/出库流程、库位优化、报表统计等。

项目愿景：通过开源降低企业数字化门槛，推动供应链管理技术共享。
